## 修复：风扇运行中从自动模式切到手动模式失败

### 根因：栈溢出（256 字节太小）

链接脚本 `Ld/Link.ld` 里 `__stack_size = 256`，但实测最深调用链需要 364 字节：

```
main(72) -> Cfg_Save(64) -> printf(36) -> print(40) -> printInt(64)
        -> prints(32) -> printchar(16) -> _write(12) = 364 B
```

wchprintf 每层栈帧都很大（printInt 单独就 64 字节），且 `Cfg_Save()` 里还有
`uint32_t buf[16]`（64 字节局部数组）。

**为什么只在"风扇运行时"出现**：风扇转��时 PC2 的 FG 方波触发 EXTI2 中断，
WCH 的 fast 中断由硬件额外压栈 40 字节（x1, x5-x7, x10-x15）。
- 风扇停止：无中断压栈 → 栈刚好够 → 正常
- 风扇运行：+40 字节 → 溢出 → 踩坏下方内存，模式切换表现异常

栈向下溢出正好落在 `.bss` 与栈底之间的区域，会覆盖全局变量。

### 改动

1. `Ld/Link.ld`：`__stack_size` 256 → **512**
   RAM 预算：.data 80 + .bss 44 + .stack 512 = 636 / 2048，仍余 1412 字节。
   修复后最深路径 364 B，含 EXTI 压栈 272 B 也有余量。

2. `User/main.c` 长按 OK 切模式处：`Delay_Ms(500)` 改为**分片延时**，
   每 100ms 调一次 `IWDG_ReloadCounter()`。原写法整段 500ms 不喂狗，
   叠加后面的 I2C 刷屏最长逼近 IWDG 的 1.67s 超时（虽然未超时，但余量只有 ~60%）。

### 已排除（非根因，勿再改）

- **EXTI ISR 未保存 `ra`**：错误。CH32V003 的 `interrupt("WCH-Interrupt-fast")`
  由硬件压栈保存 x1(ra) 等 10 个寄存器，ISR 本身无栈帧是正确的（反汇编已确认）。
- **按键状态机重复切换**：PC 模拟复现 `Key_Scan`/`Ui_HandleKey`，一次长按只触发一次切换。
- **Flash 配置区**：`.text` 止于 0x3A50，配置区 0x3FC0 安全；XIP/APB 别名用法正确。
